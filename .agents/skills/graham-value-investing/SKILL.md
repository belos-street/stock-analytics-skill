# 格雷厄姆价值投资分析技能

## 技能定位

本技能严格基于本杰明·格雷厄姆（Benjamin Graham）的投资方法论，涵盖**三大策略体系**：防御型投资者筛选、进取型投资者筛选、净净值（Net-Net）深度价值策略。核心特征是**高度量化、纪律驱动、分散持仓、价格回归即卖**，与巴菲特的"买入并长期持有优质公司"形成互补。

**与巴菲特技能的核心差异**：

| 维度 | 格雷厄姆（本技能） | 巴菲特 |
|------|-------------------|--------|
| 核心理念 | 以极低价格买入（不关心公司质量） | 以合理价格买入伟大公司 |
| 安全边际 | 50%以上（Net-Net）/ 估值极低 | 20%-40%（因公司质量而异） |
| 护城河要求 | 不要求，只要足够便宜 | 核心筛选条件 |
| 持股周期 | 价格回归即卖（1-3年） | 长期持有（5年以上） |
| 持仓集中度 | 分散（20-30只以上） | 集中（10-20只） |
| 适用标的 | 困境股、周期股、被抛弃的股票 | 成熟行业龙头、稳定盈利公司 |

## 核心分析框架

### 框架1：防御型投资者筛选标准（Defensive Investor）

适用于不愿投入大量时间研究、追求稳健回报的投资者。**7项量化标准全部满足方可入选**：

| 序号 | 筛选条件 | 量化标准 | A股适配调整 |
|------|----------|----------|-------------|
| 1 | 公司规模 | 年营收≥1亿美元 | 年营收≥50亿元人民币 |
| 2-A | 流动比率 | 流动资产≥2倍流动负债 | 同原标准 |
| 2-B | 长期负债 | 长期负债≤净流动资产 | 同原标准 |
| 3 | 盈利连续性 | 过去10年每年均有正盈利 | 同原标准 |
| 4 | 分红记录 | 连续20年以上不间断分红 | 连续10年以上不间断分红（A股分红文化较晚） |
| 5 | 盈利增长 | 过去10年每股收益增长≥33%（用首尾3年平均值对比） | 同原标准 |
| 6 | PE限制 | 当前股价≤过去3年平均EPS的15倍 | 同原标准 |
| 7 | PB限制 | 当前股价≤每股净资产的1.5倍 | 同原标准 |

**格雷厄姆数（Graham Number）**：将PE≤15与PB≤1.5合并为单一公式：

```
格雷厄姆数 = √(22.5 × 每股收益 × 每股净资产)
```

其中22.5 = 15（PE上限）× 1.5（PB上限）。当前股价低于格雷厄姆数即视为低估。

**组合规则**：至少持有10只，最多30只，单只不超过总资金10%。

### 框架2：进取型投资者筛选标准（Enterprising Investor）

适用于愿意投入时间精力研究、追求更高回报的投资者。要求更严格但标准更精简：

| 序号 | 筛选条件 | 量化标准 | A股适配调整 |
|------|----------|----------|-------------|
| 1-A | 流动比率 | 流动资产≥1.5倍流动负债 | 同原标准 |
| 1-B | 负债限制 | 总负债≤净流动资产的110% | 同原标准 |
| 2 | 盈利稳定性 | 过去5年无亏损年度 | 同原标准 |
| 3 | 分红记录 | 当前有分红 | 同原标准 |
| 4 | 盈利增长 | 最近年度EPS高于5年前 | 同原标准 |
| 5 | 估值限制 | 股价≤每股有形净资产的120% | 同原标准 |
| 6 | PE限制 | PE<10倍 | 同原标准 |

**组合规则**：至少持有20只，最多30只，单只不超过总资金5%。

### 框架3：净净值策略（Net-Net / NCAV）

格雷厄姆最极致的深度价值策略，寻找股价低于清算价值的标的：

**核心公式**：
```
净流动资产价值（NCAV）= 流动资产 - 总负债（含优先股）
每股NCAV = NCAV / 总股本
买入标准 = 当前股价 < 每股NCAV × 2/3
```

**更保守的净营运资本公式（NNWC）**：
```
NNWC = (现金 + 应收账款×0.75 + 存货×0.5) - 总负债
每股NNWC = NNWC / 总股本
买入标准 = 当前股价 < 每股NNWC
```

**筛选条件**：
1. 当前股价 < 每股NCAV的2/3（即以清算价值的67折买入）
2. 过去12个月无净亏损（剔除经营恶化的公司）
3. 剔除ST、*ST、退市风险警示标的

**交易规则**：
- 持股期间涨幅≥50%立即卖出，资金补入新符合标的
- 持股满3年若累计涨幅≤0%直接卖出，规避资金长期无效占用
- 等权建仓，单一个股权重≤3.3%（至少持有30只）

### 框架4：格雷厄姆内在价值公式

格雷厄姆在1974年提出的成长股估值公式：

```
V = EPS × (8.5 + 2R) × 4.4 / Y
```

其中：
- V = 内在价值
- EPS = 每股收益（使用过去3年平均值）
- R = 预期未来7-10年的年均盈利增长率（%）
- 8.5 = 零增长公司的合理PE
- 4.4 = 格雷厄姆时代AAA级公司债利率基准
- Y = 当前AAA级公司债利率（%）

**A股适配**：Y可使用中国10年期国债收益率或AAA级企业债收益率。

### 框架5：格雷厄姆经典价值十法（综合筛选）

格雷厄姆晚年总结的完整投资体系，分为**价值五法**和**安全五法**：

**价值五法**（关注投资价值）：

| 法则 | 量化标准 | A股适配 |
|------|----------|---------|
| V1 | 盈利回报率（1/PE）> AAA级债券收益率×2 | 盈利回报率 > 10年期国债收益率×2 |
| V2 | PE < 近5年市场最高PE的40%（或PE < 市场平均PE×0.9） | 同原标准 |
| V3 | 股息率 > AAA级债券收益率×2/3 | 股息率 > 10年期国债收益率×2/3 |
| V4 | 股价 < 每股有形净资产×2/3 | 同原标准 |
| V5 | 股价 < 每股净流动资产×2/3 | 同原标准 |

**安全五法**（关注财务安全）：

| 法则 | 量化标准 | A股适配 |
|------|----------|---------|
| S1 | 总负债 < 有形净资产 | 同原标准 |
| S2 | 流动比率 > 200% | 同原标准 |
| S3 | 总负债 < 净流动资产×2 | 同原标准 |
| S4 | 过去10年盈利总和 > 当前股本×2（即10年ROE累计>200%） | 同原标准 |
| S5 | 过去10年中盈利下滑超5%的年份≤2年 | 同原标准 |

**筛选规则**：价值五法中至少满足1项 + 安全五法中至少满足1项 = 符合格雷厄姆投资标准。

## 标准化分析流程

1. **输入信息接收**：获取目标股票代码、市场、最新股价、核心财务数据（流动资产、流动负债、总负债、有形净资产、总股本、近10年EPS、分红记录、营收）。**注明数据截止日期**。

2. **策略分类判断**：根据用户需求或标的特点，选择适用的分析框架：
   - 若用户要求"稳健筛选"或"低估值蓝筹" → 防御型（框架1）
   - 若用户要求"深度价值"或"积极选股" → 进取型（框架2）
   - 若用户要求"烟蒂股"或"净净值" → Net-Net策略（框架3）
   - 若未指定 → 默认使用框架5（经典价值十法）进行全面评估

3. **量化指标计算**：逐项计算所有量化指标，标明通过/未通过。

4. **格雷厄姆数计算**：计算格雷厄姆数并与当前股价对比，判断低估程度。

5. **内在价值测算**：使用格雷厄姆公式（框架4）测算内在价值，与当前股价对比。

6. **投资决策建议**：结合量化筛选结果与估值判断，输出具体建议。

7. **风险提示**：列出关键风险与应对方案。

## 格雷厄姆核心理念解读

### 安全边际原则

**核心理念**：以50美分买1美元的资产。

**格雷厄姆名言**："投资的精髓在于安全边际——你为一只股票支付的价格越低，你的安全边际就越大。"

**实践要点**：
- 内在价值与市场价格之间的差额就是安全边际
- 安全边际越大，投资亏损的风险越小
- 即使估值有误，足够大的安全边际也能保护投资者

### 市场先生寓言

**核心理念**：市场是你的仆人，不是你的导师。

**格雷厄姆名言**："设想市场报价来自于一个名叫'市场先生'的人，他是你的合伙人。市场先生每天都会出现，报出一个他愿意买入你的股份或卖出给你他的股份的价格。"

**实践要点**：
- 市场先生情绪不稳定，时而极度乐观、时而极度悲观
- 聪明的投资者利用市场先生的悲观（低价买入）而非被其情绪左右
- 当市场先生报出荒谬的低价时买入，报出疯狂的高价时卖出
- **不要试图预测市场先生的行为，而是利用它**

### 分散投资原则

**核心理念**：通过广泛分散降低单一标的风险。

**格雷厄姆名言**："安全边际的概念使得分散投资成为有利可图的事情。安全边际只能保证获利的机会大于亏损的机会，但不能保证不会亏损。分散化是安全边际概念的必然推论。"

**实践要点**：
- 防御型：10-30只股票
- 进取型：20-30只股票
- Net-Net策略：至少30只，格雷厄姆本人曾持有100只以上
- 单只仓位严格控制（防御型≤10%，进取型≤5%，Net-Net≤3.3%）

### 投资 vs 投机

**核心理念**：区分投资与投机是所有投资决策的基础。

**格雷厄姆名言**："投资操作是以透彻分析为基础，确保本金的安全，并获得适当的回报。不满足这些要求的操作就是投机。"

**三大要素**：
1. **透彻分析**：基于事实和数据的系统化研究
2. **本金安全**：通过安全边际保护本金
3. **适当回报**：追求合理收益而非暴利

## 方法论局限性说明

1. **净净值标的稀缺**：在现代成熟市场中，股价低于2/3 NCAV的标的极为罕见。A股中符合Net-Net标准的标的通常不足20只，多为小市值、低流动性公司。该策略在牛市中几乎无标的可选。

2. **价值陷阱风险**：格雷厄姆方法纯粹基于量化财务指标，不评估公司质量、行业前景、管理层能力。低估值可能反映的是公司基本面持续恶化（如夕阳行业、管理层掏空），而非市场错误定价。

3. **历史数据依赖**：所有指标基于历史财报，过去10年盈利稳定不代表未来不会亏损。行业结构性变化（如新能源替代煤炭、电商替代线下零售）可能使历史规律失效。

4. **流动性约束**：Net-Net标的多为小市值公司，日均成交额低，大资金难以建仓和平仓，实际执行中可能面临显著的流动性折价。

5. **A股市场特殊性**：
   - 分红文化较晚成熟，连续20年分红的标准需调整为10年
   - 壳价值、重组预期等A股特有因素可能扭曲低估值股票的定价
   - 退市机制不完善，部分"僵尸企业"长期维持低估值但不退市
   - 散户占比高，情绪驱动可能导致估值长期偏离基本面

6. **格雷厄姆公式的局限**：
   - 对增长率R的估计高度主观，微小差异会导致内在价值巨大偏差
   - 公式中的4.4/Y因子在低利率环境下可能高估内在价值
   - 不适用于亏损公司、净资产为负的公司、金融类公司（资产结构特殊）

7. **与现代市场效率的矛盾**：随着信息透明度提高和量化策略普及，格雷厄姆式的机会窗口越来越窄，持仓周期可能显著长于预期。

## 重要提醒

1. **合规性**：所有分析仅供参考，不构成投资建议
2. **风险提示**：低估值不等于无风险，价值陷阱是格雷厄姆策略的最大敌人
3. **纪律性**：格雷厄姆策略的核心是纪律——严格按量化标准筛选，不主观判断，不感情用事
4. **分散投资**：必须严格遵守分散原则，绝不对单一标的过度集中
5. **长期视角**：价格回归价值需要时间，通常1-3年，需有耐心
6. **定期检视**：每季度/半年重新验证标的是否仍满足筛选条件
