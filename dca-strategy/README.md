## 🎯 策略概述

### 515450 红利低波50ETF

- **定投频率**：月定投
- **核心特点**：防御性强、波动低、分红稳定
- **适合人群**：追求稳定现金流、风险厌恶型投资者
- **当前状态**：🟢 高性价比，建议定投1500元/月

### 159201 自由现金流ETF

- **定投频率**：周定投
- **核心特点**：弹性高、季度调仓、攻守兼备
- **适合人群**：追求收益弹性、能承受一定波动的投资者
- **当前状态**：🟢 高性价比，建议定投375元/周（1500元/月）
- **特别说明**：成立时间较短（2025年2月），PE分位参考意义有限

## 🔄 执行流程

### 515450 红利低波ETF（月定投）
1. **每月1日**：检查估值数据（PE、PB、股息率、PE分位）
2. **每月5日**：根据决策表确定金额，执行定投
3. **每季度末**：策略复盘，评估效果

### 159201 自由现金流ETF（周定投）
1. **每周一**：检查估值数据（PE、股息率、PE分位、近3月涨跌）
2. **每周二**：根据决策表确定金额，执行定投
3. **每月末**：策略复盘，评估效果

## ⚠️ 重要提醒

1. **合规性**：所有分析仅供参考，不构成投资建议
2. **风险提示**：投资有风险，入市需谨慎
3. **长期坚持**：定投效果需要时间验证，建议至少坚持3年以上
4. **分散投资**：不要将所有资金投入单一ETF
5. **定期检视**：每季度检查一次策略有效性

## 📚 使用建议

1. **新手投资者**：先从515450月定投开始，熟悉后再增加159201
2. **资金分配**：建议515450和159201按1:1或2:1比例配置
3. **记录习惯**：坚持记录每次定投，便于复盘和优化
4. **情绪管理**：市场波动时坚持纪律，不要被情绪左右
