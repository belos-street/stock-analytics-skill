### 价值表

用于判断标的是否符合价值要求。**股息率数据需通过 WebSearch 查询最新数据**（优先查询富途牛牛、理杏仁等平台的 TTM 股息率），不要使用本地 CLI 工具的 `--dividend` 参数（该参数仅返回最近一次单期分红，不准确）。

#### 倒金字塔加仓梯位

达到买入条件后，按以下梯位分批加仓（越跌越买，低位加大仓位）：

| 标的 | 梯位 | 股息率条件 | 投入仓位占比 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 招商银行 sh600036 | 第一枪 | ≥ 5.0% | 20% | 刚达到买入线，试探性建仓 |
| | 第二枪 | ≥ 5.5% | 30% | 股价再跌约 9%，加大仓位 |
| | 第三枪 | ≥ 6.0% | 50% | 股价再跌约 8%，重仓 |
| 工商银行 sh601398 | 第一枪 | ≥ 5.0% | 20% | 刚达到买入线，试探性建仓 |
| | 第二枪 | ≥ 5.5% | 30% | 股价再跌约 9%，加大仓位 |
| | 第三枪 | ≥ 6.0% | 50% | 股价再跌约 8%，重仓 |
| 中国移动 sh600941 | 第一枪 | ≥ 5.0% | 20% | 刚达到买入线，试探性建仓 |
| | 第二枪 | ≥ 5.5% | 30% | 股价再跌约 9%，加大仓位 |
| | 第三枪 | ≥ 6.0% | 50% | 股价再跌约 8%，重仓 |

> 注：投入仓位占比指占该标的**目标总仓位**的比例，而非整体账户仓位。
